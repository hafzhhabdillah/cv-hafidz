Saya adalah siswa jurusan Rekayasa Perangkat Lunak di SMK Madinatul Qur'an yang memiliki minat besar dalam dunia pengembangan web.

Saat ini, saya berfokus mendalami Front-end Development. Saya memadukan kreativitas desain antarmuka dengan logika pemrograman untuk membangun website yang responsif, interaktif, dan efisien.

Saya menikmati proses mengeksplorasi teknologi web modern seperti Tailwind CSS dan JavaScript. Saya juga aktif membangun berbagai proyek pribadi dan men-deploy aplikasi secara langsung menggunakan Vercel untuk terus mengasah keterampilan.
